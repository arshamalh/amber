The first public preview of Amber: local-first notes, typeset with Typst. 🎉

- ✍️ Notes open in a **writing view**: markup hides until you click into it; **Source** shows the plain text
- 🧮 Maths, figures and tables appear as real Typst output while you write
- ⌨️ Type `/` for headings, lists, tables, images, callouts and more
- 🗂️ Organise a vault into **chests**, each Typst or Markdown, with its own files, search and links
- 🔗 `[[Links]]` with completion, backlinks, and an offer to update them when you rename a note
- 📄 Export any note, Typst or Markdown, as a PDF
- 🔄 Amber now **updates itself**: you approve it once on first install, never again
