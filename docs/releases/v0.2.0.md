Manage your chests right from the chest switcher. 🧰

- ✏️ **Rename a chest** with the pen icon next to its name (its folder is renamed too, and links keep working)
- 🗑️ **Delete a chest** with the trash icon: type its name to confirm, and it goes to the Trash
- 📂 **Open folder as chest…** turns any folder in your vault into a chest
- ⌨️ **Rename chest…** and **Delete chest…** are also in the command list
